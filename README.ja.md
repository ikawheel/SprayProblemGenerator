# まぶし課題ジェネレーター

ボルダリングのまぶし壁の写真からホールド情報を登録し、その情報をもとに課題を自動生成できる Android アプリです。

ジムのスプレーウォールや自宅壁のような「まぶし壁」を対象に、壁画像上でホールドを登録し、スタート・ゴールやホールド数などの条件に応じた課題を生成できます。  
生成した課題は保存でき、あとから一覧や詳細画面で確認できます。

## 主な機能

- 壁画像の登録
  - カメラ撮影
  - 端末内画像の選択
- 壁画像の切り抜き
- ホールド候補の自動抽出
- ホールド形状の手動調整
- 壁サイズ推定用の基準設定
- スタート / ゴール候補の設定
- ホールド難易度の設定
- 登録済み壁からの課題作成
- 課題の保存
- 保存済み課題の一覧表示・詳細表示
- 課題画像の端末保存
- 表示色のカスタマイズ
- ライセンス表示

## 基本的な使い方

### 1. 壁を登録する

カメラで撮影するか、端末内の画像を選択して、課題作成に使う壁画像を登録します。

必要に応じて画像を切り抜き、壁として使う範囲を調整します。

https://github.com/user-attachments/assets/b3b3502b-5cba-4562-bbd8-9bca9be353a0

### 2. ホールドを登録する

壁画像上のホールドを登録します。

自動抽出で候補を作成したあと、必要に応じて手動で追加・修正・削除できます。  
小さいホールドや抽出しづらいホールドも、手動調整によって登録できます。



https://github.com/user-attachments/assets/55b3c814-50ae-44fe-bd47-2580860611b4


### 3. 課題作成用の情報を設定する

課題作成に使う補助情報を設定できます。

- 壁サイズ推定用の基準
- スタート候補
- ゴール候補
- ホールドごとの難易度

スタート / ゴール候補やホールド難易度は任意設定です。  
未設定でも課題作成はできます。

https://github.com/user-attachments/assets/07a70a82-6129-427e-9ff5-c0cfefe24729

https://github.com/user-attachments/assets/4803184a-b666-4649-8c5f-694044095a6a

https://github.com/user-attachments/assets/577b5b8f-d1ad-4a5f-a39c-bf593a807ba1


### 4. 課題を作成する

登録済みの壁情報をもとに課題を作成します。

スタート / ゴールを指定して作成する方法と、アプリに任せて作成する方法があります。

作成した課題は保存でき、あとから確認できます。

## 画面構成

主な画面構成は以下の通りです。

```text
壁一覧
 ├─ 壁の追加
 │   └─ 画像選択 / 撮影
 │       └─ 画像の切り抜き
 │           └─ ホールド登録・調整
 │               └─ 課題作成用情報の設定
 │                   └─ 壁を保存
 │
 ├─ 壁の編集
 │   ├─ ホールド調整
 │   ├─ 壁サイズ設定
 │   ├─ スタート / ゴール設定
 │   └─ ホールド難易度設定
 │
 ├─ 課題作成
 ├─ 課題一覧
 │   └─ 課題詳細
 │
 ├─ 表示設定
 └─ ライセンス
````

## 保存できるデータ

このアプリでは、主に次の情報を保存します。

### 壁データ

* 壁画像
* ホールド情報
* 壁サイズ推定用の基準
* スタート / ゴール候補
* ホールド難易度

### 課題データ

* 使用する壁
* スタート / ゴール
* 使用ホールド
* ホールドの順序
* 作成日時

### アプリ設定

* ホールド表示色
* スタート / ゴール表示色
* 線幅 ホールドの順序
* 作成日時

### アプリ設定

* ホールド表示色
* スタート / ゴール表示色
* 線幅などの表示設定
