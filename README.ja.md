# まぶし課題ジェネレーター

ボルダリング壁の写真からホールド情報を登録し、その情報をもとに課題を作成する Android アプリです。

壁画像に対してホールドの位置・属性・点数・リーチ基準を登録し、登録済みのホールド情報を使って、まぶし壁向けの課題作成を支援します。

## 概要

このアプリは、ボルダリングジムや自宅壁などのまぶし壁を対象に、以下の作業を行うためのアプリです。

- 壁画像の登録
- ホールド位置の自動抽出
- ホールド情報の手動編集
- リーチ基準の設定
- スタート候補・ゴール候補などの属性設定
- ホールドごとの点数設定
- 登録済みホールドを使った課題作成

自動抽出は完全自動化を目的としたものではなく、候補を作成する補助機能です。  
最終的なホールド情報は、ユーザーが手動で調整する前提です。

## 主な機能

### 壁の登録

壁一覧画面から新しい壁を追加できます。

新規登録の流れは以下の通りです。

1. カメラ撮影、または端末画像の選択
2. 壁画像の切り抜き
3. ホールドの自動抽出
4. 手動でのホールド編集
5. リーチ設定
6. ホールド属性設定
7. ホールド点数設定
8. 保存

### ホールド自動抽出

壁色サンプルをユーザーが画像上で指定し、その色を背景基準としてホールド候補を抽出します。

調整できる項目は以下です。

- 色幅
- 明暗幅
- 彩度下限
- 背景差しきい値

自動抽出後は、抽出結果をもとに手動で追加・削除・修正できます。

### ホールド編集

ホールド編集では、以下の操作ができます。

- ホールドの追加
- 既存ホールドへの追記
- ホールドの一部削除
- ホールド単位での削除

追加と追記は同じ画面で行えます。  
既存ホールドに触れた場合に追記として扱うか、新規ホールドとして扱うかを切り替えられます。

また、消しゴム操作によって1つのホールドが複数領域に分かれた場合は、分裂後の領域をそれぞれ別ホールドとして扱います。

### リーチ設定

画像上で2点を選択し、実際の距離を入力することで、リーチ計算の基準を設定できます。

この設定は、課題作成時の距離感の判定に利用されます。

### ホールド属性設定

各ホールドに以下の属性を設定できます。

- スタート候補
- ゴール候補

設定された属性は、課題作成時にスタート・ゴールを選ぶ際の条件として利用できます。

### ホールド点数設定

各ホールドに点数を設定できます。

点数は、課題作成時の使用範囲や難易度調整に利用します。

### 課題作成

登録済みの壁データから課題を作成できます。

課題作成には以下の方式があります。

- スタート / ゴール指定
- スタート / ゴールおまかせ

共通設定では、以下のような条件を調整できます。

- 抽選範囲
- 使用点数レンジ
- ホールド数上限
- ルート生成に関する詳細パラメータ

生成後の課題は画像上で強調表示され、再生成も可能です。

### 表示色設定

アプリ全体で使用する表示色を変更できます。

変更できる色は以下です。

- ホールド枠色
- 選択色
- 範囲選択色
- スタート / ゴール色

設定はアプリ全体で共通です。  
再起動後も保持されます。

 │               └─ ホールド編集
 │                   └─ リーチ設定
 │                       └─ ホールド属性設定
 │                           └─ ホールド点数設定
 │                               └─ 保存
 │
 ├─ 既存壁を編集
 │   ├─ ホールド編集
 │   ├─ リーチ設定
 │   ├─ ホールド属性設定
 │   └─ ホールド点数設定
 │
 ├─ 課題作成
 │   └─ 共通設定
 │       ├─ スタート / ゴール指定
 │       └─ スタート / ゴールおまかせ
 │
 └─ 表示色設定
