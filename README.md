# HoldDetector

CameraX で写真を撮影し、撮影後の画像上で手動でホールド矩形を登録するサンプルです。
UI は Jetpack Compose ベースに整理しています。

## 主な機能

- CameraX で写真を撮影
- 撮影画像を Compose で表示
- ドラッグでホールド矩形を追加
- タップでホールド選択
- 選択したホールドの削除
- 入力した件数でホールドをランダム抽選

## 構成

- `MainActivity.kt`
  - CameraX の起動、撮影、Compose UI 表示
- `MainViewModel.kt`
  - 画面状態、ホールド追加・削除、抽選ロジック
- `Hold.kt`
  - ホールド矩形モデル

## 操作

1. アプリ起動後にカメラで撮影
2. 撮影後、画像上をドラッグしてホールドを追加
3. 必要に応じてタップで選択
4. 抽選数を入力して「抽選」を押す
5. 「選択削除」で選択中ホールドを削除
